Modules
The Engine Room
Every component is purpose-built, with VPS fallbacks, caching, and graceful degradation.
🎯

Whole-Market Screener & Scoring

A dynamic Yahoo screener (EquityQuery) scans every equity in a region within the value band, sorted by volume — replacing the old ~40-ticker hardcoded pool. A curated seed pool is merged as a fallback so coverage is never lost. Brave Search adds trending signals.

🚦

Liquidity & Quality Gates

Every candidate must clear hard filters before consuming the region's analyst slot: min avg volume, min $150k/day dollar volume, $0.10 price floor, per-region exchange allow-lists (excludes OTC pink sheets), a 30% short-float cap, and a pump/blow-off guard.

🕵️

Insider Buying Signal

SEC Form 4 net-buying is folded directly into candidate scoring (cached per run): +20 for large net buys (≥500k shares), +12 otherwise, −5 for net selling. A tradeable-liquidity bonus further rewards liquid names.

📄

SEC EDGAR Ground Truth

Resolves tickers to CIK via EDGAR's company file, then reads the authoritative submissions API for 10-K/10-Q filings. Extracts MD&A and Risk Factors (skipping table-of-contents stubs) and injects real prose into the analyst prompt as hard evidence.

📊

Kelly Criterion Sizing

Computes optimal position size from historical win rate: half-Kelly with verdict scaling (STRONG BUY → 100%, BUY → 70%, WATCH → 30%), clamped to 1–25%, with a 5-trade minimum before activating.

🏦

Alpaca Paper Trading

Live broker integration for US equities — market orders for BUY / STRONG BUY, but only after a decision is explicitly accepted. Safety limits: $1 minimum order, 25% max equity per position. Dry-run when ALPACA_ENABLED is unset.

🚨

Catalyst Polling Daemon

VPS systemd timer polls every 15 min for volume spikes (>3× avg), price moves (>10%), and new SEC Form 4 filings. Fires a GitHub Actions repository_dispatch for instant single-ticker analysis.

🧪

Grading Engine (Online + Offline)

7 evaluators across two tiers. Online: format_score and verdict_validity run inline on every cron and post LangSmith feedback at zero extra LLM cost. Offline: 5 evaluators incl. LLM-as-a-Judge hallucination catchers. WATCH/AVOID verdicts auto-tag needs_review.

💾

VPS Data Layer + Live Dashboard

FastAPI + DuckDB behind Tailscale. Seen-tickers with dynamic amnesia (14d AVOID, 30d BUY). Paper portfolio with P&L tracking. Chart.js dashboard with summary cards, verdict donut, Kelly bar chart, sortable trades, and a Watchlist & Reviews panel.

🔗

Model Fallback Chain

4-stage cascade via OpenRouter (3 models + router catch-all). Auto-retry on 429s with exponential backoff, and a separate structured-output chain so framework fields survive a rate-limited model.

🔬

Prompt A/B Testing

LangSmith Hub integration with a PROMPT_VERSION env var to pin prompts to specific commits. Run parallel crons with different versions and compare results in LangSmith Experiments.

Sprint 10 — Whole-Market Discovery & Reliable Ground Truth

Dynamic Screener + Insider Scoring + EDGAR Fix

  • Dynamic whole-market screener: primary discovery via the Yahoo screener (EquityQuery + screen()) pulls every equity in-band, sorted by volume. The curated seed pool is merged as a fallback
  • Liquidity & quality gates: min avg volume, min dollar volume, price floor, exchange allow-lists, short-float cap, and a pump/blow-off guard run before the expensive analyst step
  • Insider buying in scoring: SEC Form 4 net-buying now feeds candidate ranking (+20 large net buys, +12 otherwise, −5 net selling), cached per run
  • SEC EDGAR fix: ticker→CIK resolution + submissions API replaces the ignored tickers= EFTS filter; section extraction now skips the table of contents and captures real MD&A/Risk Factors prose
  • Reliability net: new tests/test_discovery_improvements.py (32 assertions) plus a CI step running both logic suites before every hunt. Requires yfinance>=1.6, guarded so older versions fall back to the seed pool

LangGraph
Framework Features Used
Following modern LangGraph best practices throughout.
📝

Partial State Updates

Nodes return only changed keys. Annotated reducers on candidates and scores with operator.add.

🔀

Command Pattern

Gatekeeper combines a state update + routing in a single return. Routes to analyst, scout, or email.

⚡

Send API

Parallel fan-out across 4 market regions. Each region runs the full pipeline independently.

💾

Checkpointing

InMemorySaver with a thread_id for state persistence and tracing correlation.

🔄

RetryPolicy

max_attempts=3, initial_interval=2.0 on all nodes to handle transient API failures.

🏗️

Subgraphs

The multi-agent debate is a nested LangGraph subgraph — composable and independently testable.
