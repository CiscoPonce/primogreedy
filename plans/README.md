## Dependency notes

- 001 is one change on purpose. The LangSmith call updates need `langsmith` 0.15, and that pin is what lets pip install current `langchain` 1.5 and `langchain-core` 1.8. The same pin brings LangChain 1.5, whose refusal replies are content-block lists, so the `message_text` helper lands in this plan rather than after the cron has already moved.
